# PRD — بورتفوليو شخصي ديناميك بالكامل

> الإصدار: 0.1 (مسودة للنقاش)
> التاريخ: 23 أكتوبر 2026
> مرتبط بـ: `BRD.md` (الأهداف والنطاق والمراحل)
> الستاك: Next.js 16 + MongoDB

هذا الملف يشرح **ماذا** سيفعل المنتج بالتفصيل: القصص، الشاشات، الحقول، القواعد، والسلوك. الـ BRD يشرح **لماذا** ومتى.

---

## 1. المبادئ الحاكمة

1. **كل شيء بيانات:** أي نص أو صورة أو لون أو ترتيب يظهر للزائر مخزّن في قاعدة البيانات وله شاشة تعديل. لا محتوى ثابت في الكود.
2. **العربي أولاً:** التصميم والاختبار يبدآن من RTL، ثم LTR.
3. **ثنائي اللغة بالتصميم:** كل نص ظاهر للزائر شكله `{ ar, en }`.
4. **التعديل ينعكس فوراً:** حفظ في اللوحة = ظهور في الموقع بدون إعادة نشر.
5. **المالك مستقل:** أي مهمة يومية (إضافة، تعديل، إخفاء، تغيير مظهر) لا تحتاج مطوراً.
6. **لا مفاجآت للزائر:** لا وميض مود، لا قفز في اللغة، لا محتوى فارغ.

## 4. المتطلبات الوظيفية — الموقع العام

### 4.1 الصفحة الرئيسية

**FR-PUB-001 — ترتيب الأقسام ديناميك**
- الصفحة تُبنى من مجموعة `sections`: لكل قسم `key` و`visible` و`order`.
- قسم مخفي لا يظهر ولا يظهر رابطه في قائمة التنقل.
- القائمة العلوية تُبنى تلقائياً من الأقسام المرئية.

**FR-PUB-002 — القسم الفارغ**
- قسم مفعّل لكن بلا عناصر (مثلاً لا توجد آراء عملاء) لا يظهر ولا يترك فراغاً.

**FR-PUB-003 — Hero**
- يعرض: الاسم، المسمى الوظيفي، جملة تعريفية، زرّين إجراء (نص ورابط من اللوحة)، عنصر بصري.
- أول ما يظهر ويُحمّل بأولوية (LCP).

**FR-PUB-004 — النبذة**
- نص، صورة، أرقام سريعة (قابلة للإضافة والحذف: رقم + عنوان).

**FR-PUB-005 — المهارات**
- مجموعات بعناوين، كل مهارة: اسم، أيقونة، مستوى (اختياري).
- لو لم يُحدد مستوى لا يظهر شريط ولا رقم.

**FR-PUB-006 — الخبرات**
- خط زمني مرتب من الأحدث للأقدم افتراضياً (قابل لإعادة الترتيب اليدوي).
- خبرة "حالية" تعرض كلمة "حتى الآن / Present" بدل تاريخ النهاية.

**FR-PUB-007 — المشاريع (بطاقات)**
- كل بطاقة: صورة غلاف، عنوان، ملخص قصير، شارات التقنيات.
- المشاريع المميزة (`featured`) تظهر في الرئيسية؛ الباقي في صفحة "كل المشاريع" إن فُعّلت.
- النقر يفتح صفحة الـ Case Study.

**FR-PUB-008 — الخدمات**
- بطاقات: أيقونة، عنوان، وصف.

**FR-PUB-009 — آراء العملاء**
- اسم، منصب/شركة، النص، صورة اختيارية. عرض شبكة أو سلايدر (يُحدد في التصميم).

**FR-PUB-010 — قسم التواصل**
- فورم + أزرار واتساب/إيميل + روابط السوشيال. التفاصيل في 4.3.

### 4.2 صفحة Case Study

**FR-PUB-020 — المحتوى**
الترتيب المبدئي:
1. عنوان + ملخص + شارات التقنيات + الدور + الفترة
2. الفيديو التوضيحي
3. المشكلة
4. الحل
5. النتيجة
6. معرض الصور
7. الروابط (Live Demo، GitHub، أخرى)
8. تنقل: المشروع السابق / التالي

**FR-PUB-021 —** أي جزء فارغ يُخفى بالكامل (مثلاً مشروع بلا معرض صور).

**FR-PUB-022 — الفيديو**
- يُشغَّل بنقرة المستخدم (لا تشغيل تلقائي بصوت).
- لا يُحمّل الملف الثقيل قبل التفاعل (تحميل مؤجل مع صورة معاينة).
- *الطريقة (رفع/تضمين) تنتظر قرار الاستضافة، انظر القسم 13.*

**FR-PUB-023 — تتبع المشاهدة**
- زيارة صفحة مشروع تُسجَّل كمشاهدة (القسم 4.5).

**FR-PUB-024 — الرابط الدائم (slug)**
- لكل مشروع slug فريد لكل لغة أو مشترك (يُحسم في التصميم التقني)، وتغييره لاحقاً لا يكسر الروابط القديمة (توجيه 301).

### 4.3 التواصل

**FR-PUB-030 — فورم التواصل**

| الحقل | القاعدة |
|-------|---------|
| الاسم | مطلوب، 2 إلى 80 حرفاً |
| الإيميل | مطلوب، صيغة صحيحة |
| الموضوع | اختياري، حتى 120 حرفاً |
| الرسالة | مطلوبة، 10 إلى 3000 حرف |

- التحقق على المتصفح **وعلى السيرفر** (السيرفر هو المرجع).
- حماية من السبام: حقل مخفي (Honeypot) + حد معدل لكل IP + (اختياري) CAPTCHA غير مزعج.
- بعد الإرسال: رسالة نجاح بلغة الزائر وتفريغ الفورم. عند الفشل: رسالة واضحة مع الاحتفاظ بما كتبه.
- الرسالة تُحفظ في قاعدة البيانات ثم يُرسل إشعار للمالك بالإيميل. فشل الإيميل لا يلغي حفظ الرسالة.

**FR-PUB-031 — واتساب والإيميل والسوشيال**
- أزرار من بيانات الإعدادات. أي رابط فارغ يُخفى.
- رسالة واتساب افتراضية قابلة للتعديل باللغتين.

### 4.4 التنقل والعناصر العامة

**FR-PUB-040 — الهيدر:** شعار، روابط الأقسام، زرّا اللغة، زرار المود. على الموبايل قائمة منسدلة.
**FR-PUB-041 — الفوتر:** حقوق، روابط سوشيال، (اختياري) رابط للأعلى.
**FR-PUB-042 — التمرير:** سلس للأقسام (Anchor) مع تحديث القسم النشط في القائمة.

### 4.5 الإحصائيات (جمع)

**FR-PUB-050 — ما يُجمع:** زيارة صفحة، مشاهدة مشروع، اللغة، المرجع (referrer) بشكل مجمّع.
**FR-PUB-051 — ما لا يُجمع:** لا بيانات شخصية، لا عناوين IP محفوظة، لا بصمة جهاز. (بدون حاجة لشريط موافقة كوكيز إن بقينا ضمن هذا الحد، يُراجع).
**FR-PUB-052 —** عدم احتساب زيارات المالك نفسه وهو مسجل دخول.
**FR-PUB-053 —** عدم احتساب الروبوتات المعروفة.

## 5. المتطلبات الوظيفية — لوحة التحكم

### 5.1 الدخول والأمان

**FR-ADM-001 — تسجيل الدخول:** إيميل + كلمة مرور. رسالة خطأ عامة ("البيانات غير صحيحة") دون كشف أيهما الخطأ.
**FR-ADM-002 — حماية المسار:** أي مسار في اللوحة بدون جلسة صالحة يعيد للدخول. نفس الحماية على كل استدعاء سيرفر (ليس على الواجهة فقط).
**FR-ADM-003 — الجلسة:** مدة محددة، تسجيل خروج، انتهاء تلقائي.
**FR-ADM-004 — حماية التخمين:** حد لمحاولات الدخول الفاشلة مع تأخير/قفل مؤقت.
**FR-ADM-005 — المالك الأول:** يُنشأ عبر سكريبت/متغيرات بيئة، لا يوجد تسجيل عام.
**FR-ADM-006 — تغيير كلمة المرور** من الإعدادات.
**FR-ADM-007 —** (اختياري لاحقاً) مصادقة ثنائية.

### 5.2 أنماط عامة لكل وحدة محتوى

تنطبق على المشاريع والمهارات والخبرات والخدمات والآراء:

| القدرة | السلوك |
|--------|--------|
| قائمة | جدول/بطاقات مع بحث وحالة (ظاهر/مخفي) |
| إضافة / تعديل | نموذج بحقول ثنائية اللغة |
| حذف | يتطلب تأكيداً. حذف الوسائط المرتبطة يُسأل عنه |
| ترتيب | سحب وإفلات، يُحفظ فوراً |
| إخفاء/إظهار | مفتاح تبديل لكل عنصر |
| حفظ | رسالة نجاح/خطأ واضحة. تحذير عند مغادرة صفحة فيها تغييرات غير محفوظة |
| المسودة | العنصر الجديد يبدأ **مخفياً** حتى يفعّله المالك |

**FR-ADM-010 — الحقل ثنائي اللغة**
- مكوّن موحد: تبويبان أو عمودان (عربي / English) لكل حقل.
- العربي مطلوب. الإنجليزي اختياري. إن تُرك فارغاً يظهر العربي للزائر الإنجليزي (Fallback) مع مؤشر للمالك أن الترجمة ناقصة.
- شارة "ترجمة ناقصة" في القوائم للعناصر التي ينقصها الإنجليزي.

### 5.3 وحدة المشاريع

| الحقل | النوع | قاعدة |
|-------|-------|-------|
| العنوان `{ar,en}` | نص | مطلوب (عربي) |
| الرابط الدائم slug | نص | فريد، أحرف إنجليزية صغيرة وأرقام وشرطات، يُولَّد من العنوان ويمكن تعديله |
| الملخص `{ar,en}` | نص قصير | حتى 200 حرف |
| الدور `{ar,en}` | نص | اختياري |
| الفترة | تاريخ/نص | اختياري |
| صورة الغلاف | وسائط | مطلوبة للنشر |
| الفيديو | رابط/ملف | اختياري |
| المشكلة / الحل / النتيجة `{ar,en}` | نص غني | اختيارية |
| التقنيات | قائمة وسوم | من قائمة مقترحة + إضافة جديدة |
| معرض الصور | قائمة وسائط | ترتيب بالسحب، `alt` لكل صورة |
| الروابط | قائمة (تسمية + رابط) | اختيارية، صيغة URL صحيحة |
| مميز | مفتاح | يظهر في الرئيسية |
| ظاهر | مفتاح | |
| سيو `{title, description, ogImage}` | | اختياري، الافتراضي من العنوان والملخص |

**FR-ADM-020 —** معاينة المشروع بالشكل النهائي قبل النشر.
**FR-ADM-021 —** منع نشر مشروع ينقصه الحد الأدنى (عنوان عربي + غلاف + slug).
**FR-ADM-022 —** تكرار مشروع (Duplicate) كنقطة انطلاق لمشروع جديد.

### 5.4 باقي الوحدات

**الملف الشخصي والـ Hero:** الاسم، المسمى، الجمل التعريفية، نصوص وروابط الأزرار، الصورة، السيرة الذاتية PDF.
**النبذة:** النص الغني، الأرقام السريعة (قابلة للإضافة).
**المهارات:** مجموعات ومهارات بأيقونة (من مكتبة أيقونات أو رفع) ومستوى اختياري.
**الخبرات:** الشركة، الدور، تاريخ البداية والنهاية، "حالي"، الوصف، التقنيات.
**الخدمات:** العنوان، الوصف، الأيقونة.
**آراء العملاء:** الاسم، المنصب، الشركة، النص، الصورة.

### 5.5 المظهر (الثيم)

**FR-ADM-030 — المتغيرات القابلة للتحكم**

| المجموعة | المتغيرات |
|----------|-----------|
| الألوان (لكل مود: لايت ودارك) | الخلفية، سطح البطاقات، النص الأساسي، النص الثانوي، اللون الأساسي (Accent)، لون ثانوي، الحدود، النجاح، الخطأ |
| الخطوط | خط العربي، خط الإنجليزي (من قائمة معتمدة مع أوزانها) |
| الشكل | استدارة الحواف، كثافة المسافات (مريح/مضغوط) |
| الهوية | الشعار (فاتح/داكن)، أيقونة التبويب، صورة المشاركة الافتراضية |

**FR-ADM-031 — المعاينة:** معاينة حية قبل الحفظ، ثم زر "حفظ" و"تراجع".
**FR-ADM-032 — فحص التباين:** تنبيه إن كان التباين بين النص والخلفية أقل من الحد المقبول (WCAG AA) مع السماح بالحفظ بعد تحذير.
**FR-ADM-033 — الاستعادة:** زر إعادة الإعدادات الافتراضية.
**FR-ADM-034 — التطبيق:** يُطبَّق الثيم على السيرفر كـ CSS Variables داخل أول HTML، فلا وميض ولا تأخير.

### 5.6 هيكل الصفحة

**FR-ADM-040 —** قائمة الأقسام بالسحب والإخفاء، وتعديل عنوان كل قسم باللغتين.
**FR-ADM-041 —** إعدادات خاصة لكل قسم عند الحاجة (مثلاً عدد المشاريع في الرئيسية، نمط عرض الآراء).
**FR-ADM-042 —** لا يمكن إخفاء قسم "التواصل" وكل أقسام التواصل معاً دون تحذير (حتى لا يفقد الزائر وسيلة الوصول).

### 5.7 الوسائط

**FR-ADM-050 — الرفع**
- الأنواع المسموحة: صور (JPG, PNG, WebP, AVIF, SVG بحذر)، فيديو (MP4, WebM)، PDF.
- حد أقصى للحجم لكل نوع (يُحدد مع خدمة التخزين).
- التحقق من النوع الحقيقي للملف على السيرفر وليس الامتداد فقط.
- ضغط وتحويل الصور تلقائياً لأحجام متعددة.

**FR-ADM-051 —** نص بديل `alt` باللغتين لكل صورة.
**FR-ADM-052 —** يُظهر مكان استخدام كل ملف، ويحذّر من حذف ملف مستخدم.

### 5.8 الرسائل

**FR-ADM-060 —** قائمة مرتبة بالأحدث، مع حالة (جديدة/مقروءة/مؤرشفة)، عدد غير المقروء في القائمة الجانبية.
**FR-ADM-061 —** فتح رسالة يعلّمها مقروءة. زر "رد" يفتح الإيميل. حذف وأرشفة.
**FR-ADM-062 —** بحث وفلترة بسيطة.

### 5.9 الإحصائيات

**FR-ADM-070 —** بطاقات: زيارات اليوم/الأسبوع/الشهر، رسائل جديدة.
**FR-ADM-071 —** رسم زمني للزيارات (فترة قابلة للاختيار).
**FR-ADM-072 —** ترتيب المشاريع حسب المشاهدات.
**FR-ADM-073 —** توزيع اللغة والمرجع (مجمّع).

### 5.10 الإعدادات

عام (اسم الموقع)، لغة افتراضية (للحالة غير المحسومة)، مود افتراضي، بيانات التواصل، السوشيال، السيو العام، حساب المالك.

## 6. اللغات والمود

### 6.1 منطق اختيار اللغة (بالترتيب)
1. لغة محفوظة بخيار يدوي (Cookie) إن وُجدت.
2. لغة المتصفح (`Accept-Language`) إن كانت عربية أو إنجليزية.
3. غير ذلك → اللغة الافتراضية من الإعدادات (عربي مبدئياً).

### 6.2 القواعد
**FR-I18N-001 —** زرّان نصيان منفصلان "عربي" و"English" بدون إيموجي أو أعلام. الزرار النشط له حالة بصرية واضحة، وكلاهما قابل للوصول بالكيبورد.
**FR-I18N-002 —** تبديل اللغة يبقى في نفس الصفحة (نفس المشروع/القسم) لا يرجع للرئيسية.
**FR-I18N-003 —** الاتجاه `dir` و`lang` على عنصر `html` حسب اللغة.
**FR-I18N-004 —** الأرقام والتواريخ تُنسق حسب اللغة.
**FR-I18N-005 —** استخدام خصائص منطقية في CSS (start/end بدل left/right) لضمان سلامة RTL.
**FR-I18N-006 —** الأيقونات الاتجاهية (أسهم) تنعكس في RTL.
**FR-I18N-007 —** نصوص ثابتة قليلة (مثل "حتى الآن"، رسائل الأخطاء) تأتي من ملفات ترجمة، وليست من محتوى المالك.

### 6.3 المود
**FR-THM-001 —** الافتراضي حسب `prefers-color-scheme`، ما لم يضبط المالك افتراضياً ثابتاً.
**FR-THM-002 —** زرار تبديل يدوي، الاختيار يُحفظ.
**FR-THM-003 —** لا وميض عند التحميل (الاختيار يُحسم قبل أول رسم).
**FR-THM-004 —** يعمل التبديل بسلاسة دون إعادة تحميل.

## 7. تدفقات رئيسية

### 7.1 زائر جديد
1. يفتح `/` ← يُحدد اللغة ← يُوجَّه إلى `/ar` أو `/en`.
2. الموقع يظهر بمود جهازه.
3. يتصفح، يفتح مشروعاً، يشاهد الفيديو، يرجع.
4. يرسل رسالة ← تأكيد نجاح.

### 7.2 المالك يضيف مشروعاً
1. دخول ← المشاريع ← جديد.
2. يملأ الحقول (عربي، ثم إنجليزي)، يرفع الغلاف والفيديو والصور.
3. معاينة ← تفعيل "ظاهر" ← حفظ.
4. المشروع يظهر في الموقع فوراً بدون نشر.

### 7.3 المالك يغيّر الهوية
1. المظهر ← يعدّل اللون الأساسي والخط.
2. معاينة حية للمودين ← تنبيه تباين إن وُجد.
3. حفظ ← يتغير الموقع كله.

### 7.4 المالك يقرأ رسالة
1. إشعار إيميل ← يفتح اللوحة ← الرسائل ← يقرأ ← يرد عبر الإيميل.

**FR-CACHE-001 —** صفحات الموقع تُولَّد ويُخزَّن ناتجها لأقصى سرعة.

**FR-CACHE-003 —** المعيار: التعديل يظهر للزائر خلال ثوانٍ قليلة.
**FR-CACHE-004 —** *تفاصيل التنفيذ حسب ما يوفره Next.js 16 تُحسم في المرحلة 1.*

## 9. السيو

**FR-SEO-001 —** عنوان ووصف وصورة مشاركة (OG) لكل صفحة ولكل لغة، من اللوحة مع قيم افتراضية ذكية.
**FR-SEO-002 —** `hreflang` يربط النسختين العربية والإنجليزية.
**FR-SEO-003 —** `sitemap.xml` يتضمن المشاريع المرئية بكل اللغات.
**FR-SEO-004 —** `robots.txt` يمنع فهرسة اللوحة.
**FR-SEO-005 —** بيانات منظمة (Structured Data): Person للموقع، وCreativeWork/SoftwareApplication للمشاريع.
**FR-SEO-006 —** HTML دلالي: عنوان `h1` واحد في الصفحة وتسلسل صحيح للعناوين.

## 11. حالات خاصة وسلوك الخطأ

| الحالة | السلوك |
|--------|--------|
| قاعدة البيانات غير متاحة | صفحة خطأ ودية، لا تسريب تفاصيل تقنية |
| مشروع غير موجود أو مخفي | 404 بلغة الزائر |
| لا مشاريع ظاهرة | القسم يختفي بدل أن يظهر فارغاً |
| فيديو لا يعمل | عرض صورة الغلاف مع رابط بديل أو إخفاء الفيديو |
| رفع ملف كبير أو غير مسموح | رسالة واضحة، لا يُحفظ شيء |
| حفظ متزامن من تبويبين | آخر حفظ يغلب مع تحذير إن كانت النسخة قديمة |
| انقطاع الإنترنت أثناء الحفظ | رسالة فشل مع إبقاء البيانات في النموذج |
| نص إنجليزي ناقص | يظهر العربي |
| لغة المتصفح غير مدعومة | يفتح عربي |

## 12. معايير القبول العامة (Definition of Done)

لا تُعتبر ميزة منتهية إلا إذا:
1. تعمل بالعربي والإنجليزي، RTL وLTR.
2. تعمل في لايت ودارك.
3. تعمل على الموبايل والديسكتوب.
4. كل بياناتها من قاعدة البيانات ولها شاشة تعديل.
5. فيها حالات الخطأ والفراغ والتحميل.
6. التحقق على السيرفر مطبّق.
7. متاحة بالكيبورد وبـ `alt` وتباين مناسب.
8. لا تُضعف مقاييس الأداء.

### معايير قبول المنتج النهائي
- المالك ينفذ بنفسه، دون لمس الكود: إضافة مشروع كامل، تغيير الألوان والخط، إخفاء قسم، إعادة ترتيب الأقسام، قراءة رسالة، تعديل بيانات التواصل.
- الزائر يغير اللغة والمود ويتصفح ويتواصل دون أي خطأ.
- Lighthouse > 90 للأداء وإمكانية الوصول والسيو.
