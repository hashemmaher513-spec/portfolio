# Hashem Maher Portfolio — Next.js Application

تطبيق Next.js 16 (App Router + TypeScript + Tailwind CSS 4) لبورتفوليو مهندس البرمجيات هاشم ماهر.

## 🚀 أوامر التشغيل السريعة

```bash
# تثبيت الحزم
npm install

# التشغيل في بيئة التطوير
npm run dev

# فحص وبناء الإنتاج
npm run build

# تشغيل خادم الإنتاج
npm start
```
